# Tofino

Tofino is a perpetually incomplete amateur web browser that I'm building from
scratch. This is a fingerpaint project that serves no practical or industrial
purpose beyond the pursuit of craftsmanship.

The rules are:

1. No AI. Not for coding, review, troubleshooting, research, spitballing, or any
   other such crutch that disabuses me of the act of learning. This is 100% my
   own, warts and all.
2. Have fun. I used to enjoy this and I'm hoping I still might.
